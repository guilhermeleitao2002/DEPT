\section{Machine Learning for NIDS}\label{sec:bg-ml-nids}
\subsection{Learning Paradigms}\label{subsec:bg-paradigms}
\begin{itemize}
    \item Supervised (RF/TCN/meta-learner case), unsupervised (Kitsune autoencoders), semi-supervised, reinforcement learning --- when each is appropriate; ADEPT uses three of the four.
\end{itemize}
\subsection{Feature Engineering and Representation}\label{subsec:bg-features}
\begin{itemize}
    \item Static vs.\ dynamic features; packet- vs.\ flow-level granularity (traffic-space vs.\ feature-space).
    \item nPrint bit-level encoding --- why bit-level beats hand-crafted headers for cross-protocol generality; identity-field masking (src/dst IP, ports, IP~ID) to prevent overfitting to flow identity instead of behavior.
    \item Multi-rate aggregation: per-packet sequence (TCN) vs.\ prefix-checkpoint statistics at packet 2/10/20/\dots\ (RF), motivated by PortScan's $\sim$2-packet average flow length.
\end{itemize}
\subsection{Model Architectures Relevant to ADEPT}\label{subsec:bg-architectures}
\begin{itemize}
    \item Random Forests: bagging, discrete non-differentiable boundaries.
    \item 1D-CNN / Temporal Convolutional Networks: causal dilated convolutions; receptive-field math (29 packets for 3 blocks at dilation $\{2,4,8\}$).
    \item Transformers: self-attention for sequence modeling; decoder-only vs.\ encoder-only trade-offs; KV-caching for streaming inference latency.
\end{itemize}

\end{itemize}
